# CLAUDE.md

Read and follow `AGENTS.md` — it is the single source of truth for rules in this repo.
Then read the relevant file in `docs/` before working on a feature.
Project skills live in `.claude/skills/` — use them for creating pages, components,
providers and database migrations.
For any UI work, invoke the `frontend-design` skill first (installed as a plugin) and keep to
`docs/06-design-system.md` and the approved screens in `docs/design/`.
